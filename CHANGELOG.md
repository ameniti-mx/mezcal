# Changelog

Todos los cambios relevantes de Mezcal se documentan aquí.

## [0.1.0] - 2026-07-28

### Agregado

- Cliente Python tipado para consultas individuales de CEP.
- Descarga en PDF, XML y ZIP.
- Modelos Pydantic para consulta, cuentas, importes y transferencias.
- CLI con comandos `consultar`, `descargar`, `bancos` y `api`.
- API FastAPI con autenticación opcional y límites locales.
- Catálogo dinámico de instituciones con respaldo mínimo.
- Contenedor Docker y workflow de integración continua.
- Documentación de privacidad, arquitectura y uso responsable.

### Procedencia

- Basado conceptualmente y parcialmente en `cuenca-mx/cep-python`, MIT.
